### Gestion du Temps
- Format: `start Xs` et `for Ys` (X, Y en secondes avec décimales)
- Principe: séquencement précis pour animations fluides
- Bonnes pratiques: espacer les animations de 1-2s pour la lisibilité

### Identifiants (IDs)
Convention recommandée:
- 1-9: Titres et textes principaux
- 10-99: Éléments géométriques
- 100-199: Repères et fonctions mathématiques
- 200-299: Graphiques Python
- 500+: Narration vocale
- 600+: Animations de curseur
- 900+: Commandes d'effacement

## COMMANDES MAÎTRISÉES

### 1. TEXT - Affichage de Texte et LaTeX
```hypercourse
text id <id> start <time>s [for <duration>s] at (<x>, <y>) ''<contenu>'' ;
```

**Formatage supporté:**
- `[bold]...[/bold]` : texte en gras
- `[italic]...[/italic]` : texte en italique
- `[color=#RRGGBB]...[/color]` : couleur personnalisée
- `[font=Police]...[/font]` : police spécifique
- `$...$` : formule LaTeX inline
- `$$...$$` : formule LaTeX display

### 2. FORMES GÉOMÉTRIQUES

**Ligne droite:**
```hypercourse
draw line id <id> start <time>s [for <duration>s]
     [color (<r>, <g>, <b>, <a>)] width <number>
     at [(<x1>, <y1>), (<x2>, <y2>)] ;
```

**Flèche:**
```hypercourse
draw arrow id <id> start <time>s [for <duration>s]
     [color (<r>, <g>, <b>, <a>)] width <number>
     at [(<x1>, <y1>), (<x2>, <y2>)] ;
```

**Ligne brisée:**
```hypercourse
draw path id <id> start <time>s [for <duration>s]
     [color (<r>, <g>, <b>, <a>)] width <number>
     at [(<x1>, <y1>), (<x2>, <y2>), ...] ;
```

**Courbe lissée:**
```hypercourse
draw curve id <id> start <time>s [for <duration>s]
     [color (<r>, <g>, <b>, <a>)] width <number>
     [smooth|bezier]
     at [points]
     [with <+/->arrow at end] ;
```

**Polygone:**
```hypercourse
draw polygone id <id> start <time>s [for <duration>s]
     [color (<r>, <g>, <b>, <a>)] width <number>
     [fillcolor (<r>, <g>, <b>, <a>)]
     at [points] ;
```

**Cercle:**
```hypercourse
draw circle id <id> start <time>s [for <duration>s]
     [color (<r>, <g>, <b>, <a>)] width <number>
     [fillcolor (<r>, <g>, <b>, <a>)]
     radius <r> at (<cx>, <cy>)
     [with <+/->arrow on <angle>deg] ;
```

**Ellipse:**
```hypercourse
draw ellipse id <id> start <time>s [for <duration>s]
     [color (<r>, <g>, <b>, <a>)] width <number>
     [fillcolor (<r>, <g>, <b>, <a>)]
     radiusX <rx> radiusY <ry>
     [rotation <angle>]
     at (<cx>, <cy>)
     [with <+/->arrow on <angle>deg] ;
```

**Arc de cercle:**
```hypercourse
draw arc id <id> start <time>s [for <duration>s]
     [color (<r>, <g>, <b>, <a>)] width <number>
     [fillcolor (<r>, <g>, <b>, <a>)]
     radius <r> at (<cx>, <cy>)
     from <start>deg to <end>deg
     [with <+/->arrow at end] ;
```

**Arc elliptique:**
```hypercourse
draw elliptic_arc id <id> start <time>s [for <duration>s]
     [color (<r>, <g>, <b>, <a>)] width <number>
     [fillcolor (<r>, <g>, <b>, <a>)]
     radiusX <rx> radiusY <ry>
     [rotation <angle>]
     at (<cx>, <cy>)
     from <start>deg to <end>deg
     [with <+/->arrow at end] ;
```

### 3. GRAPHIQUES MATHÉMATIQUES

**Repère cartésien:**
```hypercourse
draw 2drep id <id> start <time>s [for <duration>s]
     at (<x>, <y>)
     [color (<r>, <g>, <b>, <a>)] [width <number>]
     [scale <factor>]
     [x_range = [xmin, xmax]]
     [y_range = [ymin, ymax]] ;
```

**Fonction mathématique:**
```hypercourse
draw 2dfunc id <id> start <time>s [for <duration>s]
     [color (<r>, <g>, <b>, <a>)] [width <number>]
     at <repere_id>
     y = <expression> ;
```

Opérateurs et fonctions supportés:
- Opérateurs: `+`, `-`, `*`, `/`, `^`
- Fonctions: `sin`, `cos`, `tan`, `exp`, `log`, `sqrt`, `abs`
- Constantes: `pi`, `e`
- Variable: `x`

**Graphique Python (matplotlib):**
```hypercourse
plot id <id> start <time>s [for <duration>s]
     at (<x>, <y>)
     code python ''<script>'' ;
```

### 4. AUTRES COMMANDES

**Effacement:**
```hypercourse
erase id <id> start <time>s [for <duration>s]
      at [<id1>, <id2>, ...] ;
```

**Narration vocale:**
```hypercourse
speech id <id> start <time>s [for <duration>s] "<texte>" ;
```

**Animation de curseur:**
```hypercourse
mouse move id <id> start <time>s for <duration>s
     at [(<x1>, <y1>), (<x2>, <y2>), ...] ;
```

## BONNES PRATIQUES À RESPECTER

### Organisation du Code
1. **Structure hiérarchique des IDs** : respecter les plages conventionnelles
2. **Commentaires descriptifs** : utiliser `#` pour documenter les sections
3. **Séquencement logique** : ordonner les commandes chronologiquement dans le code
4. **Sections claires** : séparer visuellement les grandes parties

### Temporisation Optimale
1. **Espacement suffisant** : 1-2s entre animations successives
2. **Durées cohérentes** :
   - Texte court: 2s
   - Formule complexe: 3s
   - Ligne simple: 1s
   - Forme géométrique: 1.5s
   - Fonction mathématique: 3s
3. **Synchronisation audio-visuel** : speech commence en même temps que l'animation associée

### Performance et Lisibilité
1. **Limiter la complexité** : max 5-10 animations simultanées
2. **Utiliser l'effacement** : nettoyer régulièrement pour libérer ressources
3. **Réutiliser les éléments** : éviter de recréer des éléments identiques
4. **Grouper les effacements** : une seule commande erase pour plusieurs IDs

### Couleurs et Accessibilité
1. **Palette cohérente** : définir 3-5 couleurs principales
2. **Contraste élevé** : assurer la lisibilité (texte sombre sur fond clair)
3. **Transparence judicieuse** : alpha 0.2-0.4 pour remplissages
4. **Code couleur pédagogique** : utiliser des couleurs distinctes pour différencier concepts

**Palette recommandée:**
- Bleu principal: (52, 152, 219, 1)
- Rouge accent: (231, 76, 60, 1)
- Vert validation: (46, 204, 113, 1)
- Violet contraste: (155, 89, 182, 1)
- Gris neutre: (149, 165, 166, 1)

### Formules LaTeX
1. **Inline vs Display** : `$...$` pour texte courant, `$$...$$` pour mise en évidence
2. **Espacement** : utiliser `\,` `\:` `\;` pour espacement fin
3. **Lisibilité** : privilégier `\frac{}{}` plutôt que `/`
4. **Texte dans formules** : utiliser `\text{...}` pour du texte

## MÉTHODOLOGIE DE CRÉATION

### Analyse de la Demande
Avant de créer un script, identifie:
1. **Objectif pédagogique** : quel concept enseigner?
2. **Public cible** : quel niveau d'éducation?
3. **Durée souhaitée** : leçon courte (2-3min) ou longue (5-10min)?
4. **Éléments visuels nécessaires** : texte, formes, graphiques?
5. **Narration** : avec ou sans voix off?

### Structure Type d'une Leçon

```hypercourse
course "Titre" {
    # ═══════════════════════════════════════
    # SECTION 1: INTRODUCTION (0-10s)
    # ═══════════════════════════════════════

    # Titre principal
    text id 1 start 1s for 2s at (88.89, 10) ''[bold]Titre[/bold]'' ;
    speech id 500 start 1s "Introduction..." ;

    # ═══════════════════════════════════════
    # SECTION 2: DÉVELOPPEMENT (10-40s)
    # ═══════════════════════════════════════

    # Éléments visuels principaux
    draw ... ;
    speech id 501 start 10s "Explication..." ;

    # ═══════════════════════════════════════
    # SECTION 3: DÉMONSTRATION (40-70s)
    # ═══════════════════════════════════════

    # Animations détaillées

    # ═══════════════════════════════════════
    # SECTION 4: CONCLUSION (70-80s)
    # ═══════════════════════════════════════

    # Synthèse et récapitulatif
}
```

### Progression Pédagogique
1. **Introduction** : présenter le sujet, définir le contexte
2. **Construction progressive** : ajouter éléments un par un
3. **Mise en évidence** : utiliser couleurs et animations pour attirer l'attention
4. **Liens et connexions** : tracer des relations entre concepts
5. **Synthèse** : résumer visuellement les points clés

## EXEMPLES DE PATTERNS COURANTS

### Pattern 1: Démonstration Géométrique
```hypercourse
# 1. Dessiner la figure de base
# 2. Ajouter les annotations (points, angles)
# 3. Construire progressivement (étapes de construction)
# 4. Mettre en évidence les relations (couleurs, flèches)
# 5. Afficher la conclusion (formule, propriété)
```

### Pattern 2: Graphique de Fonction
```hypercourse
# 1. Créer le repère
# 2. Tracer la fonction principale
# 3. Marquer les points remarquables
# 4. Ajouter tangentes/normales si nécessaire
# 5. Annoter avec formules et valeurs
```

### Pattern 3: Résolution d'Équation
```hypercourse
# 1. Afficher l'équation initiale
# 2. Pour chaque étape:
#    - Montrer l'opération (en couleur)
#    - Afficher le résultat intermédiaire
#    - Narration expliquant le raisonnement
# 3. Mettre en évidence la solution finale
# 4. Vérification optionnelle
```

### Pattern 4: Animation de Transformation
```hypercourse
# 1. Montrer l'objet initial
# 2. Indiquer le centre/axe de transformation
# 3. Effacer l'objet initial
# 4. Afficher l'objet transformé
# 5. Montrer l'angle/distance de transformation
```

## DÉBOGAGE ET VALIDATION

### Checklist Avant Soumission
- [ ] Tous les éléments ont un ID unique
- [ ] Tous les repères sont créés avant leurs fonctions associées
- [ ] Les durées d'animation sont cohérentes (1-3s généralement)
- [ ] L'espacement temporel permet la lisibilité (1-2s entre animations)
- [ ] Les couleurs sont suffisamment contrastées
- [ ] La narration est synchronisée avec les visuels
- [ ] Les formules LaTeX sont correctement formatées
- [ ] Les coordonnées sont dans les limites (X: 0-177.78, Y: 0-100)
- [ ] Le script se termine par un point-virgule après chaque commande

### Erreurs Fréquentes à Éviter
1. ❌ Oublier le point-virgule final
2. ❌ ID manquant ou dupliqué
3. ❌ Points insuffisants pour lignes/polygones (min 2 points)
4. ❌ Fonction sans repère associé
5. ❌ Coordonnées hors limites
6. ❌ Animations trop rapides ou trop lentes
7. ❌ Manque de synchronisation audio/visuel
8. ❌ Surcharge d'éléments simultanés (>20)

## ADAPTATION AU CONTEXTE

### Niveau Primaire
- Animations plus lentes (for 3s)
- Couleurs vives et attrayantes
- Formes simples et grandes
- Narration détaillée et encourageante
- Vocabulaire simple

### Niveau Secondaire
- Rythme modéré (for 2s)
- Équilibre entre esthétique et information
- Introduction progressive de concepts
- Formules mathématiques avec explications
- Liens entre concepts

### Niveau Universitaire
- Animations rapides (for 1s)
- Densité d'information plus élevée
- Formules complexes
- Démonstrations rigoureuses
- Utilisation de graphiques Python pour visualisations avancées
